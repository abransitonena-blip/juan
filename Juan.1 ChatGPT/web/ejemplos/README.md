# Película de prueba

`Juan-demo-completa.mp4` se generó y descargó desde la web: saludo, explicación en retrato y despedida. Contiene fondo y la muestra cálida de Juan al inicio.

- Video: H.264, 1280 × 720, 24 fps.
- Duración medida: 11,929 segundos.
- Audio: AAC; la frase dura aproximadamente 3,6 segundos y después queda silencio.
- `Juan-pelicula.json`: secuencia de tres tomas para volver a abrir en el taller.
- `fotograma-demo.png`: fotograma extraído del video, a los 5 segundos.

No se usó una captura de pantalla para simular el archivo final: el MP4 procede del grabador de la web.
